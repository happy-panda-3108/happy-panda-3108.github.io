마구매니저 부활 프로젝트

서비스가 끝나 앱만 남은 '마구매니저'를 되살리고 있습니다. 원작 앱을 디컴파일해 통신 규격을 읽고, 서버와 함께 사라진 규칙과 데이터는 기억과 실제 KBO 기록으로 다시 설계했습니다. 기획과 결정, 검수는 제가 하고 코드는 Claude Code 에이전트가 씁니다.

2026.02 – 현재업무

UiPath Orchestrator 세션 유지 프로그램

무인으로 도는 RPA 로봇이 멈추지 않도록 Orchestrator 세션과 망 인증을 유지하고, 끊기면 원인에 맞게 복구합니다. 끊긴 순간에는 인터넷도 쓸 수 없어 로그만 남기 때문에, 나중에 세어 볼 수 있는 로그부터 설계했습니다.

  • 27시간 재현 테스트에서 불필요한 재로그인을 1,661회에서 55회로 줄임
  • 브라우저 중단을 1초 안에 감지해 5~6초 안에 재시작
  • 인수인계 문서와 40쪽 발표 작성

Python · Playwright · pywinauto · UiPath

자세히 보기업무 프로그램이라 코드는 공개하지 않습니다

일하는 방식

  • Claude Code 세션을 역할별로 나눠 동시에 씁니다. 마구매니저는 경기 엔진 담당과 서버·기능 담당으로, 공모전은 만드는 쪽과 검증하는 쪽으로 나눴습니다.
  • 프로젝트마다 규칙 파일(CLAUDE.md)을 두고, 문제가 생기면 그 원인을 규칙으로 한 줄씩 더합니다.
  • 결정과 그 이유, 제가 입력한 기획 원문, 버전별 변경 사항을 남겨 두어 새 세션도 같은 맥락에서 시작하게 합니다.
  • 숫자로 확인하기 전에는 고쳤다고 보지 않고, 결과는 만든 세션이 아닌 다른 세션이 확인합니다.
  • 문제 정의와 결정, 실제 기기에서의 검수는 제가 하고, 코드 작성과 측정은 AI가 합니다.
