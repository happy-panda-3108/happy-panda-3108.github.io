AI와 일하는 방식

Claude Code 세션 여러 개를 역할별로 나눠 동시에 운영합니다. 다른 사람도 그대로 따라 할 수 있는 순서입니다.

규칙 파일부터

프로젝트 맨 위 CLAUDE.md에 세션별 담당 폴더, 실행 명령, '하지 말 것'을 적습니다. 사고가 나면 원인을 한 줄 규칙으로 더합니다.

세션을 역할로 나누기

게임은 엔진·시스템 세션, 공모전은 만드는 세션·검증 세션. 공유 파일은 덧붙이기만 하고, 서버 재시작·빌드 같은 일은 먼저 알립니다.

기억과 기록

결정과 이유는 장기 메모리에, 제 기획 원문은 기획기록에, 바뀐 점은 릴리즈 이력과 실험기록에 남겨 새 세션도 같은 맥락에서 시작합니다.

검증은 다른 눈으로

만든 세션이 채점하지 않습니다. 숫자로 세어 보기 전까지 "고쳤다"는 가설로 다룹니다.

사람의 몫 — 문제 정의, 선택지 중 결정, 실제 기기에서의 검수, 빌드와 서버 재시작 승인. 코드 작성과 측정은 AI가 맡습니다.
